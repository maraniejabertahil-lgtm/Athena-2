# Roadmap

V4 expands local knowledge retrieval, optional web search, browser voice input and basic API hardening.

Next milestones: (1) production identity, sessions, roles and audit logs; (2) document parsing plus embeddings/vector retrieval; (3) MCP client and permissioned plugin integrations; (4) isolated browser automation; (5) sandboxed code execution; (6) image, audio and video input/output adapters; (7) streaming, cancellation and agent orchestration; (8) full security review, load tests and deployment automation.

The goal is broad capability coverage, not a promise that a third-party model will match GPT-6 intelligence. Each feature must be tested against its connected service and documented before being marked complete. Skills are deliberately excluded.
