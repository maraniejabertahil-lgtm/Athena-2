# Skills Library

Each skill is a folder here containing a file named `SKILL.md`.
The folder name is the skill's id. The file starts with a short header that gives its `name` and `description`, followed by the instructions.

The app reads these files but never runs code from them. A skill cannot add tools or change permissions. To add a skill, create a new folder with a `SKILL.md` file, then restart the server.
